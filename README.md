# Projeto_imc

Aplicação web simples para cadastro de pessoas e cálculo de IMC.

## Funcionalidades
- Cadastro de pessoas (Nome, Sexo, Data de Nascimento, Peso, Altura)
- Cálculo automático de idade e IMC
- Listagem dinâmica de pessoas cadastradas
- Diferenciação visual baseada na situação do IMC
- Remoção de registros

## Tecnologias Utilizadas
- HTML5
- CSS3 (Layout Responsivo)
- JavaScript (Puro / Vanilla JS)

## Estrutura do Projeto
- `index.html`: Estrutura da página
- `css/style.css`: Estilização e responsividade
- `js/script.js`: Lógica de negócio e manipulação do DOM
